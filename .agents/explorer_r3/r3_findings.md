# Configuration Mismatch Audit Report (R3)

**Target Project**: ProjectRosaura (`f:\htdocs\ProjectRosaura`)  
**Audit Scope**: Docker compose files, Dockerfiles, environment files (`.env`, `.env.example`, `.env.ws`, `.env.ws.example`), database managers, Stripe configurations, route mappings (PHP backend & JS frontend).  
**Mode**: Read-Only Audit

## Edge Cases

| # | Feature | Input / Condition | Observed Behavior |
|---|---------|-------------------|-------------------|
| 1 | Database Connection (`DatabaseManager`) | Non-standard MySQL port specified in `.env` (`DB_PORT=3307`) | `DatabaseManager` ignores `DB_PORT` and attempts connection on default port 3306, resulting in PDO connection timeout / `SYSTEM_DB_OFFLINE`. |
| 2 | Worker Status Check (`CheckWorkerStatus`) | Frontend invocation via `ApiRoutes.Admin.CheckWorkerStatus` | Frontend posts `route: 'admin.backups.check_worker_status'`, but backend is registered as `'admin.check_worker_status'`. Backend responds with 404 `error.route_not_found`. |
| 3 | Standalone WebSocket Startup | `docker-compose -f docker-compose.ws.yml up` | `websocket_node` container starts up, but port 8765 is not exposed to host, preventing client connections. |
| 4 | Telemetry Database Operations | Distinct telemetry DB user credentials configured in `.env` (`DB_TELEMETRY_USER`) | `DatabaseManager` connects using global `DB_USER` instead of `DB_TELEMETRY_USER`. If permissions differ, telemetry queries fail with Access Denied. |
| 5 | Canvas Chunk Loading in Production Cluster | Deploy stack initialized via `deploy/docker-compose.app.yml` & `deploy/docker-compose.data.yml` | `go_service` is not included in `deploy/` compose files. Frontend canvas chunk requests (`/api/go/canvases/get_chunks`) fail with HTTP 502/500 proxy error. |
| 6 | Admin System Settings Panic/Cache Actions | Triggering `Admin.TogglePanicMode` or `Admin.MaintenanceClearCache` in Admin UI | Request fails with HTTP 404 `error.route_not_found` because these routes exist only in frontend `ApiRoutes.js` and lack backend endpoints. |
| 7 | MinIO Client in Local Cluster | `deploy/docker-compose.local-cluster.yml` environment initialization | `AWS_ENDPOINT` set to `minio:9000` (missing `http://`). PHP S3 client throws `InvalidArgumentException: Invalid endpoint URL`. |
| 8 | Stripe Webhook Direct Dispatch | Webhook posted to `/api/index.php?route=stripe.webhook` | `api/index.php` returns 404 `error.route_not_found` because webhook route is not mapped in `route-map.php`. Webhook must be pointed to `/stripe/webhook.php`. |
